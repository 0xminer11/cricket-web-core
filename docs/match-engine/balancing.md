# Balance methodology

See [MODULE-8-BALANCE-REPORT.md](MODULE-8-BALANCE-REPORT.md) for measured values. Module 0 targets: dot 25–42%, single 22–34%, two/three 8–16%, four 10–18%, six 5–12%, wicket 4–9%, extras 2–7%. First innings averages: two-over 16–28; five-over 42–65.

Delivery categories are exclusive: wicket first, extras next, otherwise runs/dot. Runs per ball includes penalty and bat runs. Representative equal players have 55 in cricket/physical skills. Weak/strong are 30/80; elite/elite 90. All tests use fixed seeds; statistical guards are broad and comparisons paired.

Every balance constant is in game-core, not a hidden service multiplier. The initial balance is not a claim of launch-final realism. Extreme skill matchups intentionally fall outside representative aggregate targets. Track them separately. Golden changes require a version explanation; never weaken a failed balance assertion merely to hide a regression.
