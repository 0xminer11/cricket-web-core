# Batting resolution

All twelve Module 0 shots are supported with their category, ideal line/length, foot preference, risk, power multiplier, timing difficulty and direction arc. Suitability separately rewards line and length fit; footwork recovers only a small part of mismatch. Physical reflex assists timing, while placement controls directional spread.

Human timing is -1 (early), 0 (ideal), +1 (late). Missing timing is generated from a separate seeded contact stream using timing skill and shot difficulty. Aggression in [0,1] modestly increases both boundary power and wicket risk, defaulting to neutral 0.5. Direction input selects a point in the shot's arc. There is no automatic correction of a mismatched shot.

World direction mirrors the batter-relative angle for left-handers; scoring sectors retain off/leg semantics. No character mesh or animation determines a result. Physical strength contributes modestly to boundary power; cricket skills remain primary.
