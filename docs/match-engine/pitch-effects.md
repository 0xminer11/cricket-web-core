# Pitches

Existing Module 0 definitions drive all multipliers. Green increases seam/swing; hard increases pace and bounce; dry increases spin and slightly lowers speed. Movement affects contact challenge and continuous wicket/boundary weights, so pitch effects still matter when contact stays within the same band.

Paired-seed tests compare resolved movement directly. The balance report compares aggregate fast/spin output across all three pitches. Effects are intentionally modest; pitch does not overpower a large skill gap.
