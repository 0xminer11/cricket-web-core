# API

All routes are under `/api/v1`, use the Module 1 envelope and Module 3 cookie sessions, require a trusted `Origin` on `POST`, and return `Cache-Control: no-store`. Terminology: the API says **player**; the game UI says **cricketer**.

## `GET /player/creation-options` (auth required)

Everything the wizard may offer, derived from game-core: `gameBalanceVersion`, `nameRules`, `jerseyRange`, `heightRange`, `countries` (`priority`, `all` ISO codes), `battingHands`, `bowlingStyles`, `roles[]` (id, name, description, strengths, typicalPosition, bowlingExpectation, `bowling` required/optional, `allowedBowlingStyles`, and `previews` keyed by style or `none` with the **exact** starting `attributes` and `overall`), `personalities[]` (with resulting traits), `appearance[]` (starter options only), and `starter` (tier, team, level, coins, gems, loadout with item names). Balance weights and formulas are not exposed.

## `POST /player` (auth required; guests allowed)

Headers: `Idempotency-Key: <16-128 chars [A-Za-z0-9_-]>` (recommended; generated by the web client once per wizard).

```json
{
  "displayName": "Naveen Kumar",
  "countryCode": "IN",
  "jerseyNumber": 18,
  "battingHand": "right",
  "primaryRole": "top_order_batter",
  "bowlingStyle": "right_arm_medium",
  "appearance": {
    "bodyPresetId": "appearance.body.athletic_01",
    "facePresetId": "appearance.face.preset_01",
    "skinToneId": "appearance.skin.tone_04",
    "hairStyleId": "appearance.hair.short_01",
    "hairColorId": "appearance.haircolor.black",
    "beardStyleId": "appearance.beard.none",
    "heightScale": 1
  },
  "personalityArchetypeId": "personality.balanced",
  "gameBalanceVersion": "1"
}
```

`bowlingStyle` may be `null`/omitted for batting roles. `gameBalanceVersion` is optional and informational. **Any other field is rejected.**

Responses: `201 { success, data: { player, created: true } }`; `200 { …, created: false }` for an idempotent replay. `player` is the full profile below.

| Status | Code                                                                                                                                                                                                                                   | When                                                        |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| 400    | `VALIDATION_ERROR`                                                                                                                                                                                                                     | wrong shape, unknown/forbidden field, bad `Idempotency-Key` |
| 400    | `INVALID_PLAYER_NAME`, `INVALID_COUNTRY`, `INVALID_JERSEY_NUMBER`, `INVALID_PLAYER_ROLE`, `INVALID_BATTING_HAND`, `INVALID_BOWLING_STYLE`, `ROLE_BOWLING_STYLE_MISMATCH`, `INVALID_APPEARANCE_OPTION`, `INVALID_PERSONALITY_ARCHETYPE` | a choice is refused                                         |
| 401    | `AUTH_REQUIRED`                                                                                                                                                                                                                        | no valid session                                            |
| 403    | `ACCOUNT_SUSPENDED`, `CSRF_ORIGIN_INVALID`                                                                                                                                                                                             |                                                             |
| 409    | `CRICKETER_ALREADY_EXISTS`                                                                                                                                                                                                             | the user already has a cricketer                            |
| 422    | `IDEMPOTENCY_KEY_REUSED`                                                                                                                                                                                                               | same key, different decisions                               |
| 429    | `RATE_LIMITED`                                                                                                                                                                                                                         |                                                             |
| 500    | `PLAYER_CREATION_FAILED`                                                                                                                                                                                                               | unexpected failure; everything rolled back                  |

(`CREATION_CONFIG_CHANGED` is reserved for a release that removes an option mid-wizard; today such a case surfaces as the specific invalid-choice code.)

## `GET /player` (auth + cricketer required)

The caller's own cricketer: `{ player: { summary, overall, attributes, personalityArchetypeId, appearance, xp, fatigue, career, equipped, createdAt } }`. `summary` is the reusable `PlayerSummary` (`id`, `displayName`, `countryCode`, `jerseyNumber`, `primaryRole`, `battingHand`, `bowlingStyle`, `level`, `overall`, `careerTier`, `form`). `overall` = `{ player, batting, bowling, physical }` (derived on read). `404 CRICKETER_NOT_FOUND` before creation. No user id, wallet, ledger, idempotency data or database ids other than the player/career ids are exposed.

## `POST /player/creation/events` (auth required)

Best-effort funnel analytics: `{ event: 'started' }`, `{ event: 'step_completed', step: 1..5 }`, `{ event: 'role_selected', role }` → `cricketer_creation_started`, `cricketer_creation_step_completed`, `cricketer_creation_role_selected`. Server-side events: `cricketer_creation_completed` (role, personality, accountType, balance version), `player_created`, `career_started` (Module 0 names). All carry only the pseudonymous user id.

## `/api/v1/me`

`hasCricketer` is true as soon as the player row exists (checked by the Module 3 `currentUser`).
