# Testing

```bash
pnpm test                    # unit tests incl. the engine (no database)
pnpm test:integration        # + API/database (needs docker compose up -d)
pnpm test:e2e                # Playwright
pnpm simulate:training       # balance report
```

E2E arranges hard-to-reach states (a player one XP from a level, a skill one point from the next, 59 coins) with a small direct database helper (`e2e/support/db.ts`), then drives the real UI and API and asserts what the server did.

## Mapping to the brief

Concurrency (items 116-118), idempotency (119), rollback (120), level-up (121-122; multi-level is an engine test because no single drill grants enough XP to cross two levels), skill-up (123), multi-skill (124), max skill (125), diminishing returns (126), fatigue bounds (127), currency exact and short (128-129), roles and bowling style (130-131), new and high-level players (132-133), zero and high fatigue (134-135), mobile (136), accessibility (137-138).
