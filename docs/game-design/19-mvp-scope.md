# 19 — MVP vs Post-MVP vs Future

## MVP
- User profile and create cricketer
- Player attributes/roles/personality basics
- Career dashboard
- Targeted training
- Equipment + inventory + deterministic upgrades
- Academy→Club progression path implemented on top of extensible six-tier data
- AI opponents
- 2-over and 5-over formats
- Batting and bowling
- Match rewards, player XP, Skill XP, Coins
- Form, fatigue, fans, career reputation, selector interest
- Basic events/contracts/achievements/objectives
- Save progress
- Server authority for valuable outcomes
- Headless match simulation tests

## Post-MVP
- Full six-tier career content
- Deeper contracts/sponsors
- More shots/deliveries
- Richer wicket types, field settings and run mechanics
- Expanded wicketkeeper/fielding attributes
- PWA/mobile wrapper optimization
- Seasons/LiveOps and additional cosmetics

## Future
- T10/T20/ODI/Test-like formats
- Leagues/tournaments
- PvP/matchmaking/rankings
- Weather gameplay
- Injuries/recovery depth
- Captaincy/tactical field settings
- Social/club systems
- Marketplace/trading only if economy/security design later justifies it

Multiplayer is explicitly not an MVP dependency.
